Mods for Geometry Dash 2.2091, today.

Reode is a mod manager with its own SDK. It installs in one click, backs up your saves before any mod runs, and starts without mods if something goes wrong.

Download ReodeSetup.exe Source code Discord Windows · Steam version · public beta

What you get

One-click setup

The installer finds the game in your Steam library. Uninstalling puts the game back exactly as it was.

Your progress is safe

The first start copies your save files to a backup that is never deleted. Every start after that adds a fresh one.

Safe mode

After a crash the next start loads no mods. Hold Shift while the game starts to skip mods any time.

Clear mod list

The R button in the main menu lists every mod. If one did not load, it tells you why.

An SDK for modders

C++23 headers, a project template and a 15-minute guide from nothing to a running mod.

Open source

Every release is built from the public code by GitHub Actions, with checksums and a VirusTotal report.

Comes with

Fast Transitions

Shorter fades between menus and levels.

Screenshot

F12 saves the screen as a PNG and copies it to the clipboard.

Clock

The time and how long you have played, in the corner. F9 hides it.

Questions

Is it safe?

The code is public, releases are built from it by GitHub Actions, and each release lists SHA-256 checksums. Download Reode only from its GitHub releases page.

Does it run Geode mods?

No. Reode has its own mods and SDK. If Geode is installed, the installer sets its loader aside, and uninstalling Reode puts it back.

How do I remove it?

Run ReodeSetup.exe again and choose Uninstall. Your saves and backups stay where they are.
